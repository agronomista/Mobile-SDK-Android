# DJI Mobile SDK v4 Sample Code

## Requisitos básicos

- Android Studio abierto en esta carpeta (`Sample Code`).
- La clave de DJI ya está declarada en el `AndroidManifest.xml` del módulo `app`.
- El `applicationId`/package debe coincidir con el registrado en DJI Developer (por defecto: `com.dji.sdk.sample`).

## Ejecutar el sample

1. Abre esta carpeta en Android Studio.
2. Sincroniza Gradle.
3. Ejecuta en un dispositivo físico con Internet activo para registrar el SDK.
